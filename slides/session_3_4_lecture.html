Learn

Recognize identifiers and minimize the input

  • In the fictional practice message, a person's name, phone number, account ID, and invoice ID are identifying details. The task only needs to know that a customer reports a damaged package and asks what to do. Removing unnecessary details reduces exposure. Removing a name alone does not guarantee anonymity if other details can still identify the person.
Learn

Check authorization before using a tool

  • A safe workflow begins with the organization's approved-tool and data-handling rules. If policy is unknown or the tool is not approved for customer data, do not upload the message; ask the responsible person. A classroom prompt is not permission to paste real customer records into a public AI service.

Learn

Review the minimized output

  • When policy permits the task, use only the minimum necessary facts. Check that the draft does not repeat private details, invent a refund promise, or state a policy that was not supplied. A person remains responsible for verifying accuracy, policy fit, tone, and privacy before a reply is sent.
Apply

Three-step method

  • Identify what is sensitive; check whether the tool and task are approved; minimize data and review the output before use.

A clearer, safer prompt

Use

Improved example 1

Before using AI, list the data fields in this sample that should be removed
or replaced. Do not draft a reply or repeat the identifiers.
Use

Improved example 2

Assume company policy permits an approved AI tool for this task.
Draft a neutral reply using only these facts: the item arrived damaged;
the customer asks for next steps. Ask the customer to use the secure support
channel to provide order details. Do not promise a refund or repeat identifiers.
