Lesson explanationSession 4.4

Learn

Make a prompt card usable by someone else

  • A prompt card should state the task, intended user, required input, copyable prompt, output format, limits, and review checks. Placeholders show exactly what a teammate must replace. Include a small example input so a new user can tell what belongs in each field.
Learn

Make boundaries and missing information explicit

  • For meeting notes, the prompt must not assign an owner or date unless the notes state one. If a field is missing, use "Not stated" and place it under Open Questions. State when the prompt should not be used, such as when notes include information the user is not authorized to share with the AI tool.

Lesson explanationSession 4.4

Understand the idea and apply it

Learn

Test the handoff, not just the prompt writer

  • Give the card to a classmate without explaining it verbally. Ask them to use it on a new set of short notes and note confusing fields, invented claims, and missed safeguards. Compare the result with the input, revise the card once, and record what changed. A portfolio artifact should show this test and its limits, not claim that AI output is automatically correct.
Apply

Three-step method

  • Choose one prompt that solves a real repeated task; document inputs, instructions, and boundaries; have a classmate test and review it.
