What problem are we solving?

Learn how to document a tested prompt as a prompt card: fill in seven fixed fields, test the card with a new user, and include clear limits and human checks.

The situation

The problem

Rina's weekly recap template from Session 4.1 works well. Next week she goes on vacation, and her teammate Marco must write the recaps. Her root problem is that Marco has never used the template. She sent him only the prompt text in a chat message. Marco pasted the notes in the wrong place, used the prompt on a customer email, and sent a recap with a wrong date without checking it. Rina's idea is to ask ChatGPT to write instructions for the prompt. ChatGPT wrote a 300-word description that called the prompt "powerful" and "time-saving," but it did not say what to paste, when not to use it, or what to check. A useful prompt needs a short card that another person can follow alone.

Five documentation words you need first

Before you share a prompt, you must know these words. Each example uses Rina's recap template.

Key idea

Prompt card

A short page that explains one tested prompt with fixed fields, so anyone can use it the same way.

Key idea

Handoff

Giving your work to another person so they can do it without you. Example: Marco writes the recaps while Rina is away.

Key idea

Input instructions

Exactly what to paste and where. Example: "Paste this week's meeting notes in place of {Meeting_Notes}."

What the AI often answers

A typical result

A long, friendly description that says the prompt is "powerful" and "saves hours," with general tips such as "review the output."

Why it is weak

Reasons

  • It does not include the prompt, so the AI describes a prompt it has never seen.
  • It gives no fields, so the AI writes marketing text instead of instructions.
  • Nothing in the answer says what to paste, when not to use the prompt, or what to check.

AI Chat
You
Now test the card. Act as Marco, a new teammate who has never seen this prompt.
Read only the card, not this conversation.
List up to three things that are unclear or missing for you.
For each one, suggest one sentence to add to the card.
Then show the revised card.
Message AI...
Why it works

Reasons

  • Acting as a new user finds gaps that the writer cannot see.
  • "Read only the card" makes the test fair: Marco will not have this chat.
  • Up to three items keeps the revision small and focused.
  • The revised card is ready to save in the team's shared folder.
