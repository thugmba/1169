Learn

Calculate an estimate before ranking

  • Estimated monthly time saved equals minutes saved per use multiplied by monthly uses. From the fictional candidates, A is 5 x 20 = 100 minutes, B is 10 x 4 = 40 minutes, and C is 30 x 1 = 30 minutes. These are estimates based on the exercise assumption that each prompt saves half the original time, not measured or guaranteed savings.
Learn

Compare value and risk, not just a large number

  • A prompt used often may be more useful than a dramatic one-off task. Consider usefulness, repeat frequency, consistent output, ease of reuse, and the cost of an error. A high estimated time saving does not make a prompt safe or accurate. Score candidates with the same criteria so the comparison is fair.

Test the leading prompt on fresh input

  • Choose one prompt to polish, then ask a partner to run it with a new input. Record one quality issue and whether the prompt handled the new case. Explain one reason not to choose each alternative. Do not convert saved minutes into a money claim unless a separate, supported cost calculation is available.
Apply

Three-step method

  • Estimate time saved; score prompts against shared criteria; select one to improve and explain the trade-off.
