Problem firstSession 2.4

What problem are we solving?

Root problem: few people try the team's budgeting app.

Root problem

Few people try the app

  • A student team is building a budgeting app.
  • 60 students saw the ad. Only 12 tried the app.
  • The ad said "Take control of your money!" and spoke to no real need.
The team's idea

Let AI create personas

  • AI could describe the customers and write better ads.
  • But the profiles must come from real evidence.
What went wrong

An invented customer

  • ChatGPT created "Sarah, 24, marketing assistant, earns $3,500, loves yoga, syncs her bank accounts."
  • None of it came from the six interviews.
  • The ad promised bank syncing, which the app does not have.

Today's goal and a three-step method

Use AI to build customer profiles from evidence, not from imagination.

Step 1

Give the AI the evidence

  • Paste the interview notes and product facts.
  • Tell the AI to "use only" them.
Step 2

Require a note for every detail

  • Each need and barrier cites a note ID.
  • Check each citation yourself.
Step 3

Check every message

  • Use only available features.
  • Label untested claims "Hypothesis."

Part 3 | The fixSession 2.4

How the three-step method fixes the profile

The instructor runs the prompts below and compares the answers.

Step 1 fixes

The evidence problem

  • The AI can only use what people actually said.
Step 2 fixes

The trust problem

  • Every need and barrier has a note ID you can check in seconds.
  • A detail with no note becomes a question for the next interview.
Step 3 fixes

The false-promise problem

  • Each message names the feature it uses.
  • Unavailable features cannot appear.

We are building a budgeting app. Use only the interview notes and product facts below.

N5: I already use a spreadsheet. I would switch only if tracking takes less time.
N6: I do not want a new app to connect to my bank account.
Group the notes by similar need. Make two customer profiles.
Each profile needs at least two notes with the same need.
For each profile, give: the need, the supporting note IDs, one barrier with its note ID,
the available feature that fits the need, and one question for the next interview.

Do not write ads yet.

Why it works: improved prompt 1

Each part of the prompt matters.

Why it works

Reasons

  • It gives the AI the six notes and the product facts, which fixes the missing evidence in Poor Prompt 1.
  • "Every detail must cite a note ID" makes each detail easy to check.
  • "At least two notes with the same need" stops the AI from building a profile on one comment.
  • "Do not add age, job, income, or hobbies" removes the invented details from Poor Prompt 2.
  • "Do not write ads yet" keeps understanding the customer and selling to the customer as separate steps.

Hour 3 | Exercise 2Session 2.4

Exercise 2: Place new interview notes

The team runs two more interviews. Where does each new note belong?

How it works

Fit, or wait for more evidence

  • Compare the new note with each profile's notes.
  • A profile needs at least two notes with the same need.
  • If no feature meets the need, write "Not available."
  • Never promise a feature the app does not have.
Template - replace each [part], then send
AI Chat
You
Continue with the same notes, product facts, and profiles.
Here is a new interview note: [note ID and text].
Does it fit Profile A, Profile B, or neither? Cite the note IDs you compare it with.
Remember: a profile needs at least two notes with the same need.
Which available feature, if any, meets this need? If none, write "Not available."
Do not promise a feature the app does not have.
