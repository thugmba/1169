Core idea

The Cost of Unstructured Prompts in Business (15 min)

  • When employees give ambiguous prompts, ChatGPT generates an "average" response that requires multiple cycles of manual editing. Every cycle wastes valuable business hours. Prompt architecture provides the model with the exact structural boundaries it needs to produce workplace-ready output on the very first try.
Core idea

The 4-Box Prompt Architecture Framework (15 min)

  • Teach the 4 modular building blocks:
  • Role / Persona: Establishes the authoritative viewpoint, tone, and professional vocabulary (e.g., "Senior Product Marketing Director").
  • Business Context: The operational backdrop, target customer, problem being solved, and market conditions.
  • Task Directive: An unambiguous command verb stating the exact deliverable (e.g., "Draft a launch announcement memo").
  • Output Format Template: The exact schema, headings, bullet counts, and sections required.

Core idea

Delimiters and Modular Prompt Design (10 min)

  • Why delimiters matter: Using symbols like ###, ---, or """ clearly separates instructions from raw data. This prevents the model from confusing text to analyze with commands to execute, establishing clean prompt hygiene.
Core idea

Instructor Live Demonstration Script & Discussion (10 min)

  • Live Demo: Extract 4 facts from a corporate press release on PR Newswire. Type a 4-box modular prompt live on screen into ChatGPT to draft an internal company briefing. Show how defining the Output Format Template ensures the AI never outputs conversational pleasantries like "Sure, here is your email!". Discussion Question: "If you omit the Output Format Template, what default formatting mistakes does ChatGPT typically make?" (Answer: It produces rambling introductory paragraphs, inconsistent bullet points, and excessive sign-offs).
