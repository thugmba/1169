What problem are we solving?

Learn how to turn a weekly task into a reusable AI template: fix the output sections, add a rule for missing information, and reuse the same template by changing only the input.

The situation

The problem

Rina leads a small website team. Every week, someone spends about 30 minutes writing the meeting recap from scratch, and the recaps look different each time. Her root problem is that tasks get lost: last month, two tasks were missed because no one was named as the owner. Her idea is to let ChatGPT write the recap. She pasted the notes and asked, "Summarize these meeting notes." The summary was smooth, but it said, "Priya will handle the legal review by Friday." The notes do not name anyone for the legal review. The summary also left out the decision to postpone the pricing page. The AI filled gaps and dropped a decision because the prompt gave it no format and no rule for missing information.

Goal and methodSession 4.1

Today's goal and a three-step method

Learn how to turn a weekly task into a reusable AI template: fix the output sections, add a rule for missing information, and reuse the same template by changing only the input.

Step 1

Fix the output

Decide the same sections for every week, such as Decisions, Actions, Open questions, and Next meeting.

Step 2

Add a rule for missing information

Tell the AI to write "Not stated" when an owner or a date is not in the notes.

Step 3

Reuse and check

Save the prompt as a template with a placeholder. Each week, change only the notes and check the output against them.

Five workflow words you need first

Before you build a reusable prompt, you must know these words. Each example uses Rina's weekly recap.

Key idea

Recurring task

Work that happens again and again in the same way. Example: the weekly meeting recap.

Key idea

Template

A prompt you save and reuse. Only one part changes each time: the input.

Key idea

Placeholder

A marked spot in the template where the new input goes. Example: {Meeting_Notes}.

Output format

The fixed sections the answer must have. Example: Decisions; Actions (Task, Owner, Due date); Open questions; Next meeting.

"Not stated" rule

An instruction for missing information. If the notes do not name an owner, the AI writes "Not stated" instead of guessing.

What the AI often answers

A typical result

A smooth paragraph that says "Priya will handle the legal review by Friday," does not mention the pricing page, and adds "The meeting went well."

Why it is weak

Reasons

  • It gives no output sections, so the AI chooses what to include and can drop a decision.
  • It gives no rule for missing information, so the AI fills the missing owner with a guess.
  • The format changes every week, so the team still has to read every recap carefully.

Why it works: improved prompt 1

Each part of the prompt matters.

Why it works

Reasons

  • The four fixed sections make the AI look for decisions, actions, and questions every time.
  • The Task | Owner | Due date table shows at once which tasks have no owner.
  • "Not stated" stops the invented owner from Poor Prompts 1 and 2.
  • "Do not add anything" removes filler such as "the meeting went well."
  • "Use only the notes" keeps the recap faithful to what the team said.

Exercise 1: Build the template

Guided practice. Follow the steps in order.

Guided practice

Steps

  1. Open ChatGPT and start a new chat. Copy Poor Prompt 1 from the box above, paste it, and send it. Write down any owner or date in the summary that is not in the notes, and any decision that is missing. You will need them for your report.
  2. Start another new chat, so the first answer does not affect the second. Copy Improved Prompt 1, paste it, and send it.
  3. Compare the recap with the notes and with the answer key below. Check that the legal review says "Not stated" and that the pricing page decision is included.
  4. In the same chat, copy Improved Prompt 2, paste it, and send it. Save the template the AI gives you in a document.
  5. For the Results section of your report, write the errors from Step 1 and the recap from Step 3.
