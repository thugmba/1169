What problem are we solving?

3 hours: 50-minute lesson, 10-minute break, 50-minute guided practice, 10-minute break, 50-minute applied practice, and 10-minute wrap-up.

Situation

The problem

A small online shop receives return questions. A broad AI prompt may sound friendly but give an incorrect answer. Students need a way to improve an answer and check it against the policy.

Target

Learning goal

Diagnose one output weakness, change one prompt instruction, and compare the result against the same source policy.

Learn

Treat the policy as the source of truth

  • The AI should classify a request using the shop's stated rules, not a general idea of what seems fair. An unopened item with a receipt and a return within 14 days can qualify for a refund. An item reported damaged within 7 days can qualify for a replacement. Those are different outcomes. If a required detail is missing, ask for it instead of promising an exception.
Learn

Diagnose the answer before changing the prompt

  • A reply can sound warm and still be wrong. Check whether it names the correct outcome, gives a reason from the policy, and avoids unsupported promises. Compare the output with cases A-D: A is refund eligible, B is replacement eligible, C is not eligible for a standard refund, and D needs an order number. Write down the exact error before editing anything.

Learn

Change one instruction and rerun the same cases

  • Keep the policy and customer messages fixed. Change one instruction, such as requiring a policy-based label or a next step when information is missing. Compare the original and revised answers against the same cases. A change log records the weakness, the one prompt change, and whether accuracy improved. Changing many instructions at once makes it hard to tell what helped.
Apply

Three-step method

  • Run a short prompt; identify one visible weakness; change one instruction and compare both outputs against the policy.

A clearer, safer prompt

Keep the source, task, constraints, and output check visible.

Use

Improved example 1

Use only the policy and customer messages below.
For each case, label the result Eligible, Not eligible under the stated policy,
or Information needed. Give one policy reason. Do not invent exceptions.
Use

Improved example 2

Draft a separate reply for each customer using only the policy.
Start with the result, give one brief reason, and state the next step.
If information is missing, ask for it without promising approval.
Keep each reply under 50 words.
