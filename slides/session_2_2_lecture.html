What problem are we solving?

Root problem: Leo spends about two hours a day answering return emails.

Root problem

Too many return emails

  • Leo runs a small online phone accessory shop.
  • He receives about 20 return emails a day.
  • Answering them takes about two hours.
Leo's idea

Let AI draft the replies

  • AI could write a first draft of each reply.
  • Leo would only check and send.
  • But every reply must follow the return policy.
What went wrong

Friendly, but wrong

  • Leo asked: "Please reply to these customer emails."
  • The AI promised refunds that break the policy.
  • Two wrong promises were worth $70.00. The prompt did not include the policy.

Part 1 | Policy wordsSession 2.2

Return policy, refund, and replacement

Before you ask an AI to answer customers, know what the policy words mean.

Word 1

Return policy

The shop's written rules about returns.

The AI must follow these rules, not its own idea of what is fair.

Word 2

Refund

The customer gets the money back.

Phone case returned: $25.00 back

Word 3

Replacement

The customer gets a new item instead of money.

Example: a cracked screen protector is replaced with a new one.

Part 1 | Policy wordsSession 2.2

Return window and order number

Example: an item delivered on March 1.

Word 4

Return window

The number of days a customer has to ask.

Refund window: March 1 + 14 days = March 15

Damage window: March 1 + 7 days = March 8

Word 5

Order number

The code that identifies a purchase, such as #4471.

  • When a receipt is missing, the shop uses the order number to check the purchase.
  • The shop checks first, and decides after.

What the AI often answers

A typical result

Four friendly replies that all offer a refund, for example: "We're sorry the earbuds didn't work out for you. We'll be happy to process your refund."

Why it is weak

Reasons

  • It does not include the return policy, so the AI uses a general idea of good service instead of the shop's rules.
  • It does not ask the AI to decide a result for each case before writing, so the decision is hidden inside polite sentences.
  • The result is a set of promises that break the policy and could cost the shop $70.00.

Why it works: improved prompt 1

Each part of the prompt matters.

Why it works

Reasons

  • It gives the AI the policy and says "use only" this policy, which fixes the problem in Poor Prompt 1.
  • It limits the result to four labels, so every decision is easy to compare with the answer key.
  • It asks for the rule number, so you can see which rule the AI used for each case.
  • "Do not invent exceptions" removes the pressure to say yes that caused the problem in Poor Prompt 2.
  • "Do not write the replies yet" keeps deciding and writing as separate steps.

Improved prompt 2 - copy and send
AI Chat
You
I checked your table against our policy. The results are correct:
A Refund, B Replacement, C Not eligible, D Information needed.

Now write one reply for each customer. Rules for every reply:
- Say the result in the first sentence.
- Give the reason from the policy in one sentence.
- Tell the customer the next step.
- If information is missing, ask for it and do not promise a refund.
- Be polite. Keep each reply under 60 words.
Message AI...
Why it works

Reasons

  • It gives the AI the checked results, so the replies cannot change the decisions.
  • It sets the order of each reply (result, reason, next step), so customers get a clear answer.
  • It keeps the "do not promise" rule for Case D, the case where the AI made a costly mistake.
  • "Be polite" is still there, so the replies stay friendly without breaking the policy.
