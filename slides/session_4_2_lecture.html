Situation

The problem

A campaign prompt can produce a polished plan even when the budget or audience is missing. A confident-looking guess can mislead the team.

Target

Learning goal

Test a prompt with complete and incomplete inputs, then add a useful fallback for missing information.

Lesson explanationSession 4.2

Learn

Find the inputs a recommendation depends on

  • The practice request identifies a reusable bottle and local students, but does not state budget, channel, or success measure. Those gaps matter because they affect spending and how the team evaluates the campaign. A polished AI plan does not make missing facts true.
Learn

Choose a fallback that matches the missing detail

  • The prompt can ask a few important questions, mark unknown fields "To confirm," or draft a limited outline that avoids spending recommendations. Do not ask questions that would not change the next step. Do not invent a budget, channel, or sales result to make the plan look complete.

  • Run a baseline prompt; note any invented or unclear detail; add one fallback rule and rerun the same case.

A clearer, safer prompt

Keep the source, task, constraints, and output check visible.

Use

Improved example 1

List the known campaign facts and the missing details.
Do not invent a budget, channel, or performance result.
Ask up to three questions that would materially change the plan.
Use

Improved example 2

Draft a low-cost planning outline using only the known facts.
Mark budget, channel, and success measure as "To confirm";
do not recommend spending or claim expected sales.
End with the three questions needed before launch.
