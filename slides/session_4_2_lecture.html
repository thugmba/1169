What problem are we solving?

Learn how to test and fix a prompt: run it with complete and incomplete inputs, find where it invents information, and add one fallback instruction until it handles missing facts safely.

The situation

The problem

Joon is a marketing intern at a small shop that sells eco-friendly products. His manager asked for a two-week social media plan for a new reusable bottle. The brief did not include the budget, the channel, or the success measure. Joon's root problem is that he must deliver a plan quickly, but key facts are missing. His idea is to let ChatGPT write the plan. The plan looked ready to approve: "Budget: $5,000. Channel: influencer ads. Goal: 1,000 sales." All three numbers and choices were invented. The real budget, which the manager gave later, was $300. The AI filled the gaps because the prompt never told it what to do when information is missing.

Step 1

Test with different inputs

Run the prompt with a complete brief and with briefs that miss information.

Step 2

Find the bug

Count the details in the answer that are not in the input. Each invented detail is a bug.

Step 3

Patch and retest

Add one fallback instruction for missing information, then run all the tests again.

Part 1Session 4.2

Five testing words you need first

Before you fix a prompt, you must know these words. Each example uses Joon's campaign brief.

Key idea

Test input

One version of the brief that you use to try the prompt. Example: Test 2 has a budget but no channel.

Key idea

Bug

A repeated wrong behavior in the answer. Example: the AI invents a budget whenever the budget is missing.

Key idea

Fallback instruction

A rule for what the AI must do when information is missing. Example: "If the budget is missing, write 'Missing: budget' and ask for it."

Part 1Session 4.2

Five testing words you need first (continued)

Before you fix a prompt, you must know these words. Each example uses Joon's campaign brief.

Key idea

Patch

A small change to the prompt that fixes one bug. Change one instruction at a time, so you know what helped.

Key idea

Retest

Run all the test inputs again after a patch. A fix for one input must not break another.

Part 3Session 4.2

How the three-step method fixes the prompt

The instructor runs Poor Prompt 1 and Improved Prompts 1 and 2 below in front of the class and compares the answers.

Key idea

Step 1 fixes the hidden-bug problem

A prompt that works on one complete brief may fail on an incomplete one. Testing several inputs shows the bug.

Key idea

Step 2 fixes the "looks fine" problem

Counting invented details turns a feeling into a number you can compare after the patch.

Key idea

Step 3 fixes the bug safely

One fallback instruction, then a retest of all inputs, shows whether the patch worked without breaking anything.

What the AI often answers

A typical result

A complete-looking plan with a budget of several thousand dollars, influencer ads, daily posts, and a sales target.

Why it is weak

Reasons

  • It does not list which facts are known and which are missing.
  • It has no fallback instruction, so the AI fills every gap with a guess.
  • The guesses look like facts, so a manager could approve the wrong budget.

Improved prompt 1

Steps 1 and 2. Copy this prompt exactly.

Improved prompt 1 - copy and send
AI Chat
You
You help plan small social media campaigns. Use only the brief below.

Brief:
- Product: reusable water bottle, $18 each
- Audience: local university students
- Timing: two weeks
- Budget: not provided
- Channel: not provided
- Success measure: not provided

Before you plan anything, check each field and mark it Provided or Missing.
For each missing field, write "Missing: [field]" and ask one question about it.
Do not invent any budget, channel, goal, or number. Do not write the plan yet.

Why it works: improved prompt 1

Each part of the prompt matters.

Why it works

Reasons

  • It lists every field, so the AI can see exactly what is missing.
  • "Mark it Provided or Missing" makes the gaps visible before any planning.
  • "Missing: [field]" is the fallback instruction that fixes the bug in Poor Prompts 1 and 2.
  • One question per missing field gives Joon a short list to ask his manager.
  • "Do not write the plan yet" keeps checking and planning as separate steps.

Improved prompt 2

Improved prompt 2 - copy and send
AI Chat
You
My manager answered two questions: the budget is $300, and the success
measure is 100 visits to the product page in two weeks.
The channel is still not decided.

Now draft a two-week plan that stays within $300.
Show how the $300 is split; the total must be $300 or less.
Suggest two channel options and label each one "Option to approve."
Label any number you estimate as "Estimate."
Message AI...
Why it works

Reasons

  • It adds only the facts the manager gave, so the plan uses real numbers.
  • "The total must be $300 or less" gives a limit you can check with a calculator.
  • "Option to approve" keeps the undecided channel as a choice, not a fact.
  • The "Estimate" label shows which numbers are guesses.
