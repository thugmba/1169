Learning goal

Concept and methodSession 4.2

Concepts for this problem

Keep each concept tied to the practical decision.

Understand

Core concepts

  • A required input is information needed to make a responsible recommendation.
  • A fallback tells the model what to do when that input is absent: ask, label an assumption, or provide only a limited draft.
  • Test the same prompt with normal and incomplete cases so you can see what the change actually improves.
  • Avoid asking for needless clarification when a safe, useful partial answer is possible.
Apply

A simple method

  • Run a baseline prompt; note any invented or unclear detail; add one fallback rule and rerun the same case.

Compare examplesSession 4.2

A clearer, safer prompt

Keep the source, task, constraints, and output check visible.

Use

Improved example 1

List the known campaign facts and the missing details. Do not invent a budget, channel, or performance result. Ask up to three questions that would materially change the plan.
Use

Improved example 2

Draft a low-cost planning outline using only the known facts. Mark budget, channel, and success measure as 'To confirm'; do not recommend spending or claim expected sales. End with the three questions needed before launch.
