### Session Report: Every Week

- **Due:** 23:59 on the day of the class
- **Submit on:** iLearn
- **Format:** Microsoft Word (.docx)

After each session, submit one report written in the [report template](Report_template.docx). Every report has the same four sections: **Introduction** (the business problem and your goal), **Method** (the full prompts you used), **Results** (the AI output and what you checked), and **Conclusion** (your recommendation, one supporting fact, and one remaining uncertainty). See the **Report** list at the end of each session for what to put in each section. **Exception:** Session 3.3 uses a worksheet instead of the report template. Submit the completed worksheet for that session.

- **How to submit:** Download the template and write your report in Microsoft Word. Save a copy with the new file name below; do not submit the file as `Report_template.docx`. Upload it to **iLearn** by **23:59 on the day of the class**.
- **Example report:** See a completed report for Session 2.1: [James_S1234567_W5_Menu.docx](examples/James_S1234567_W5_Menu.docx). Use it to see how much to write and how to show prompts, tables, and checks.
- **File name:** `FirstName_StudentID_W#_Keyword.docx`
  - **FirstName:** your first name in English, for example `James`.
  - **StudentID:** your student ID, for example `S1234567`.
  - **W#:** the week of the 16-week semester (W1 to W16, one session per week), for example `W5`. Do not write `W05` or `W#5`.
  - **Keyword:** one English word you choose that describes the report topic, for example `Menu`. For a two-word topic, join the words: `GrossProfit`.
  - Use underscores (`_`) between the four parts. Do not use spaces.
  - Correct example: `James_S1234567_W5_Menu.docx`
  - Wrong examples:
    - `James_W5_Menu.docx`: the student ID is missing.
    - `James_S1234567_W05_Menu.docx`: the week has an extra zero. Write `W5`.
    - `James S1234567 W5 Menu.docx`: it uses spaces instead of underscores.
    - `Report_template.docx`: the template was not renamed.
    - `James_S1234567_W5_Menu.pdf`: the file is not a Word file. Submit a `.docx` file.
